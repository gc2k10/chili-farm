# Contributing

All project documentation, issues, pull requests and code comments must be in English.

Open an issue describing the proposed change, then work on a separate branch. Keep changes focused, document limitations and include test evidence. Never submit credentials, private configurations or production logs. Use synthetic examples. Hardware and administrative changes require isolated testing and safe defaults.

By submitting a contribution, you agree to license your contribution under the project's MIT License. Only submit material you have the right to contribute.
