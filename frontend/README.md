# Frontend demo

A standalone responsive dashboard using synthetic data only. No backend, credentials or device controls are required.

Open index.html in a browser, or from the repository root run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory frontend
```

Visit http://127.0.0.1:8000. The period selector changes the synthetic history chart. Browser and mobile testing remain pending. This is not a production dashboard.
