# ChiliFarm v0.1.0-demo

First standalone frontend demonstration. This is a prerelease, prepared as a draft for review.

## Included

- Branded dashboard and project presentation, with approved original logo and favicon assets.
- Synthetic metric cards, status examples and selectable 24-hour / 7-day history.
- Responsive chart labels that remain readable at phone widths.
- A 44-pixel minimum-height period selector and visible keyboard focus.
- A demo-only ZIP, local-start instructions, license, file manifest and archive checksum.
- Automated Chromium, Firefox and WebKit checks at 320, 390, 768 and 1280 pixel widths.

## Run

Extract the ZIP and follow README.md. Python 3 can serve the extracted directory on http://127.0.0.1:8000; no application dependencies or credentials are required.

## Validation

See docs/demo-validation.md in the repository, or VALIDATION.md in the package. The draft workflow reruns browser checks for the release commit and only creates the draft if they pass.

## Limitations

Synthetic data only. No backend integration, real monitoring, hardware control, authentication or persistence. No physical mobile-device tests, full accessibility audit, payment-flow tests or full-history security audit are claimed. This release does not validate sensors, irrigation or electrical safety.
