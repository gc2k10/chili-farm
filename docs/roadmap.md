# Plan rozwoju

| Etap | Kryterium zakończenia |
| --- | --- |
| Oświetlenie | Harmonogram lampy sprawdzony po zaniku i powrocie zasilania |
| Pomiar gleby | Powtarzalne odczyty w docelowej doniczce |
| Hydraulika | Zmierzona dawka, sprawdzona szczelność i zachowanie po wyłączeniu pompki |
| Automatyka lokalna | Próba blokady przy pustym zbiorniku, błędzie pomiaru i restarcie. Zweryfikowane limity czasu pracy i odstępu między dawkami |
| Telemetria | Raspberry Pi 5 zapisuje historię. Pico zachowuje lokalne ograniczenia po utracie łączności |
| Panel | Odczyty, historia, stan zbiornika i przyczyny blokad. Sterowanie ręczne z uwierzytelnieniem i egzekwowaniem limitów na Pico |
| Zdjęcia | Galeria montażu i dokumentacja wzrostu |

Zdjęcia montażu można dodać w `docs/photos/` i podlinkować w instrukcji sprzętowej. Przed publikacją usuń metadane lokalizacji i sprawdź, czy w kadrze nie ma prywatnych informacji. Do przykładów konfiguracji używaj wartości opisowych. Dane uwierzytelniające i rzeczywiste logi przechowuj poza repozytorium.
