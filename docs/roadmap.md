# Development roadmap

| Milestone | Acceptance criteria |
|---|---|
| Lighting | Schedule verified after power loss and restoration |
| Soil sensing | Repeatable readings in the target pot |
| Hydraulics | Measured dose, leak checks and verified shutdown behavior |
| Local automation | Empty-tank, sensor-failure and restart interlocks tested; runtime and cooldown limits verified |
| Telemetry | Raspberry Pi 5 stores history; Pico enforces local limits when offline |
| Dashboard | Readings, history, tank status and interlock reasons; authenticated manual control with Pico-enforced limits |
| Photography | Assembly gallery and plant growth documentation |

Add assembly photos under docs/photos/ and link them from the hardware guide. Remove location metadata and inspect images for private information before publication. Use placeholders in configuration examples. Keep credentials and real logs outside the repository.
