# ChiliFarm branding

The approved ChiliFarm wordmark is the owner-supplied original PNG. `frontend/assets/brand/chilifarm-original.png` is a byte-for-byte copy: no redraw, recoloring, retouching, cropping or geometry changes.

The same original is used on light and dark surfaces, retaining its light background and natural aspect ratio. Do not apply CSS filters or stretch it.

The favicon and Apple touch icon use the original pepper detail, cropped without the neighboring letters, centered on a white square and resized for their target sizes. The ICO contains 16, 32 and 48 pixel PNG frames. These are derived icons, not replacement wordmarks.

README, the demo dashboard and the project presentation reference these assets. GitHub Pages stages only the four explicitly named brand files, alongside the existing HTML, CSS and JavaScript. Source screenshots, payment screenshots, QR codes, configuration files and other repository content are excluded.
